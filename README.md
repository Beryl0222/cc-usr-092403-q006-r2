# 老红橘保护性收购

广兴镇老红橘接入饮料企业原料链后的收储结算与溯源服务：追踪地块、老树群、
管护记录、采收批次、检验等级、企业交货四条线的连续关系，并在并发与断网
场景下保证「每公斤果实只结算一次、保护树不越界、价格不回溯」。

## 领域模型与连续溯源链

```
农户 ─ 地块 ─ 树群(普通老树/百年保护树)
                │  管护记录（含护树队病害上报）
                ▼
            采收批次（保护树先预占配额）
                │  过磅单（批次+流水号幂等，断网可重传）
                ▼
            检验样本（初检定级、封存留样）
                ▼
            企业交货（锁定交货时适用价规版本）
                ▼
            农户结算（逐磅单计价固化）
                │
   ┌────────────┼─────────────┐
   ▼            ▼             ▼
企业退货     运输损耗      果肉加工路线
（独立流水） （独立流水）    （陈皮等，独立流水）
```

## 强制不变量（由 `domain.py` 校验，测试逐条证明）

1. **同一批果不重复结算**
   - 过磅单按 `(批次, 过磅流水号)` 幂等：断网地磅恢复后重传纸质磅单只返回原单，
     不二次入库（含 8 线程并发同号提交测试）。
   - 结算以未结算磅单为粒度，已结算磅单被结算单永久引用；并发结算第二次返回
     `already_settled`。
2. **保护树采收不越界**：百年保护树按采收季下达重量+次数配额；采收前按批次
   预占（跨批次汇总核额），过磅回冲预占，超采当场拒绝；无配额不得采收。
3. **价格不回溯**：合约记录签约时价规版本；交货时锁定当时适用价规，应收金额
   随结算固化。之后市场价涨跌只能发布价规新版本，历史结算分文不改。
4. **复核留痕与价差**：质量复核改级时，原检验记录与封存样本保留（标为非现行），
   新记录标注「复核自」。结算前改级按新等级计价；结算后改级另出**价差调整**
   （补付/扣回），不覆盖原结算行。
5. **四条独立流水**：农户结算 / 企业退货 / 运输损耗 / 果肉加工分账；退货不冲减
   农户应收；数量勾稽 `退货 ≤ 到货 ≤ 交货核定`，加工投入不得超过来源可处置量。
6. **护树队最小权限**：只能上报病害/违规采摘、查看裁剪后的树群视图；结算、
   账本、批次、过磅、反查一律 403。
7. **成品原料反查**：企业可从交货单或陈皮加工路线反查地块、树群、管护记录、
   历次检测依据（含样本编号）与实际受益农户；只能反查本企业的交货单。
8. **农残复核异常召回**：
   - 召回可从 **地块 / 过磅批次 / 加工批次 / 成品** 任一节点发起，沿
     「来源 → 投入/成品」父子数量关系定位下游货权节点，形成带版本号的范围；
     同批货在链上只计一次（已成品的量留在成品节点，加工批只承载在制余量）。
   - 按节点当前保管方分派 **隔离 / 拦截 / 退回 / 销毁 / 解除 / 替代交付** 任务。
     **扩大范围补建任务；缩小范围不自动释放已被人工隔离的货物**，须监管/合作社
     显式解除。
   - 离线回执按回执号幂等、重复通知按内容指纹去重，都只产生一次业务效果；
     回执数量与系统受控量冲突时挂起，等待**监管人员授权复核**（维持/调整）。
   - 原始检验与历史结算不可改写；确认受影响后以**追加账**记录暂缓/追回/恢复
     金额（从成品发起时按父子构成摊回来源磅单，以结算固化单价计价），与等级
     申诉价差调整各走各的账；确认未受影响自动恢复。处置中的磅单触发结算
     `recall_hold` 闸门。
   - 结案必须同时交代 **数量守恒**（受控=销毁+退回+替代交付+解除）、
     **未回执节点** 与 **每笔资金变化**。
   - 护树队、农户、加工方、监管人员各自只能看到履职所需的数据。

## HTTP 接口

除 `GET /health` 外均需 `X-Actor-Token` 头，JSON 收发；业务错误返回
`{"error": 代码, "message": ...}`（401/403/404/409/422）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/actors` | 登记身份令牌（角色：果农/合作社/质量复核人/护树队/收购企业/加工方/监管人员） |
| POST | `/farmers` `/plots` `/trees` | 农户、地块、树群建档 |
| POST | `/quotas` | 保护树按季配额（重量+次数） |
| POST | `/cares` `/reports` | 管护记录；护树队上报病害/违规采摘 |
| POST | `/batches` `/reservations` | 开立采收批次；保护树额度预占 |
| POST | `/weigh` | 过磅（支持毛重/皮重、断网标记；批次+流水号幂等） |
| POST | `/inspections` `/reviews` | 初检定级封存样本；复核改级 |
| POST | `/price-rules` `/contracts` | 发布不修改的价规版本；签约锁定基准价规 |
| POST | `/deliveries` `/settlements` | 交货锁价；合作社逐磅单结算（召回中触发 recall_hold） |
| POST | `/returns` `/losses` `/processing` | 退货 / 损耗 / 陈皮等加工三条独立流水 |
| POST | `/processing-batches` `/goods` | 加工方建档加工批次（逐笔来源投入）；成品入库/在途上报 |
| POST | `/recalls` | 从 地块/过磅批次/加工批次/成品 发起召回（监管人员） |
| POST | `/recalls/{id}/scope` | 扩大/缩小范围，生成新版本（扩补建、缩不自动放人工隔离） |
| POST | `/recalls/{id}/notify` `/receipts` | 处置通知（内容去重）；保管方回执（回执号幂等、支持断网离线） |
| POST | `/recalls/{id}/release` | 显式解除人工隔离货物 |
| POST | `/recalls/{id}/conflicts/{cid}` | 监管对数量冲突授权复核（维持/调整） |
| POST | `/recalls/{id}/funds/hold` `/claim-back` `/restore` | 资金追加账：暂缓/追回/恢复 |
| POST | `/recalls/{id}/confirm` | 复核结论（确认受影响/未受影响，未受影响自动恢复资金） |
| POST | `/recalls/{id}/close` | 结案：数量守恒+未回执节点+资金变化报告 |
| GET | `/batches` `/batches/{id}` `/trees/{id}` | 链上查询（按角色裁剪） |
| GET | `/settlements/{id}` | 结算单（含价差调整） |
| GET | `/ledgers/{农户结算|企业退货|运输损耗|果肉加工}` | 分账导出 |
| GET | `/trace?delivery=…` 或 `?route=…` | 成品原料反查 |
| GET | `/recalls` `/recalls/{id}` `/recall-tasks` `/recall-tasks/{id}` | 召回查询与保管方履职任务视图（按角色裁剪） |

## 运行与测试

```bash
python3 service.py --check     # 基础配置检查
python3 service.py --port 8000 # 启动服务
npm test                       # 59 个用例：契约 + HTTP 集成 + 领域不变量（含并发/召回）
python3 -m compileall -q .     # 编译检查
```

## 文件

- `domain.py` — 领域对象、四流水、召回处置与全部不变量（线程安全，内存存储）。
- `service.py` — HTTP 适配层与路由，不含业务规则。
- `test_domain.py` — 47 个领域用例，含断网重放、并发过磅/结算/申诉、
  保护树配额、价差方向、价格不回溯、反查链，以及召回范围版本/扩缩/幂等/
  冲突授权/资金追加账/守恒结案/角色隔离。
- `test_api.py` — 9 个 HTTP 用例，验证鉴权、错误码、端到端流程与召回全生命周期。
- `service_contract.py` — 健康检查与路由暴露的原始契约。
- `fixtures/domain.json` — 统一领域称谓与不变量清单。
